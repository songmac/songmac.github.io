### 01. 토픽 시작하기

데이터 시각화를 한다면?

- 수치 데이터로 봤을 때와는 달리 보이지 않던 질문의 답을 찾을 수 있음
- 이 데이터가 어떤 패턴이나 추세를 가지고 있는지 알 수 있음

→ 일상생활에서 시각화를 통해 유용한 정보를 찾아 의사결정에 사용

기존의 데이터 시각화 방법 : ppt, excel, python

그러나, 기존의 데이터 시각화 방법과는 다르고 훨씬 편리한 방법이 바로 tableau

- 코딩 불필요
- 데이터를 드래그, 값을 바꿔가며 차트와 실시간 상호작용 가능
- 예쁘고 직관적

태블로 시각화 유형

- 시트(차트 1개)
- 대시보드(여러 개의 시트를 한 화면에)
- 스토리(시트나 대시보드를 좌우로 연결)

### 02. 태블로와 친해지기

1. 파일 열기
   - ‘파일’ 탭 → ‘열기’ → 문서 → 내 리포지토리 → 데이터 원본
2. 데이터와 처음 만나기
   - 행 : 데이터의 기록들
   - 열 : 데이터들의 속성
   - 자료형 : 문자, 날짜, 숫자
3. Tableau 인터페이스 살펴보기

   - 인터페이스 구성
     - 데이터원본 시트 영역(필드/속성)
     - 데이터베이스 연결 영역
     - 워크 시트 영역
       - 시트 내에서는 인터페이스의 주요 영역들을 패널(판)이라고 부름
       - 패널로 편집한 데이터들을 그때 그때 요약해서 보여줌
   - 패널 구성
     - 태블로 로고 패널(시작페이지로 돌아가기)
     - 상단 패널(차트 편집 기능 모아놓기)
     - 데이터 패널(필드 모아놓기)
     - 행/열 패널(가로/세로 모양 결정하기)
     - 마크 패널(각 버튼을 눌러 차트 색상/속성 변경하기)
     - 표현방식 패널(현재 데이터로 만들 수 있는 활성화된 그래프 중 선택하여 변경하기)
     - 분석 패널(데이터를 바탕으로 간단한 분석하기)

4. 데이터와 필드 파헤치기
   - 데이터 패널
     - 차원(선 위 필드) : 측정 값을 집계(측정 값을 요약)하는 기준
       - 파란색으로 표시(태블로에서 불연속형 데이터로 가정)
     - 측정값(선 아래 필드) : 데이터 분석을 통해 알고자 하는 어떤 값
       - 초록색으로 표시(태블로에서 연속형 데이터로 가정)
     - (참고)연속형 데이터와 불연속형 데이터
       - 불연속형 데이터?
         - 두 지점 사이에 몇 개의 값이 존재하는지 명확 i.g. 물병 개수
         - 문자열 데이터 i.g. 요일, 사람 이름
       - 연속형 데이터?
         - 두 지점 사이에 무수히 많은 데이터가 있음 i.g. 1~3 cm 사이의 값
       하지만, 차원/측정값 개념과 연속형/불연속형 개념은 서로 별개 !
5. 다양한 집계 방법 살펴보기
   - 합계, 평균, 중앙값
   - 카운트, 카운트(고유), 최소값, 최대값, 백분위수
   - 분산, 분산(모집단)
     - 분산 : 데이터가 평균으로부터 흩어진 정도를 측정하는 방법 중 하나. 편차의 제곱의 평균
       - 데이터의 분산이 작다는 것은 평균 근처에 데이터가 많이 몰려 있음을 의미
       - (참고) 분산을 이해하는 데 필요한 개념
         - ‘편차’는 데이터의 값에서 평균값을 뺀 것을 의미
         - ‘모집단’은 어떤 조사나 분석의 대상이 되는 전체 집단을 의미
         - 모집단 중에서 일부분만 추출해낸 그룹을 ‘표본’이라고 함
     - 분산과 분산(모집단) 중 무엇을 써야 할 지 확신이 서지 않을 때는 대부분 '분산'을 사용하는 것이 좋음
     - 분산을 구할 때는 편차 제곱의 합을 (값의 개수-1)로 나누고, 분산(모집단)을 구할 때는 (값의 개수)로 나눔
   - 표준편차, 표준편차(모집단)
     - 표준 편차 : 표준편차 역시 데이터가 평균으로부터 흩어진 정도를 나타내는 방법 중 하나. 분산에 양의 제곱근
       - 분산은 계산 과정에서 편차를 제곱하기 때문에, 원래 값들의 크기에 비해서 큰 수치가 나오는 문제가 존재. 따라서 분산보다는 표준편차를 더 많이 사용
6. 차원/측정값과 자료형 설정하기
   - 차원/측정값은 자료형과는 별개의 개념임
     - 기본적으로 태블로가 자동으로 차원 또는 측정값 으로 분류
       - 각 데이터를 살펴보고 사용자가 판단하여 우클릭으로 차원/측정값 변환 가능
       - 별칭으로 범주의 이름 변경 가능
7. 파일 저장하고 불러오기
   - 파일 저장하기 : ‘파일’ → ‘저장’ 또는 ‘Tableau Public에 저장’ 또는 ‘ctrl + S’
     - 시트를 하나 이상 만들면 로그인 후 파일로 저장 가능
     - 웹페이지에 들어가면 작업하던 파일만 노출됨 (+나머지 시트도 함께 저장)
   - 파일 불러오기
     - 태블로 종료 했다가 다시 실행시켜서 작업하던 시트 클릭
     - 오른쪽 상단에 Tableau Public에서 열기 클릭
8. 파일 관련 문제 해결하기
   - 원본 데이터 파일의 데이터가 변경 되었을 경우
     - ‘데이터 원본’ 탭 → ‘새로고침 아이콘’
     - 시트 내 ‘데이터 패널’ → 우클릭 해서 ‘새로고침’
   - 원본 데이터 파일의 이름/경로가 수정되었을 경우
     - ‘데이터 원본’ 탭 → ‘연결’ → 우클릭 해서 ‘파일 변경’
     - 시트 내 ‘데이터 패널’ → 우클릭 해서 ‘새로고침’ → 파일 변경
   - 원본 데이터 파일의 열이름을 수정했을 경우
     - 시트 내 ‘데이터 패널’ → 테이블 속성 우클릭해서 ‘참조 바꾸기’
   - 실습 환경에 따라 가끔 태블로가 강제종료 될 수 있으니 중간 저장 필수 !

### 03. 다양한 시각화 방법 익히기

1. 차트 제작의 기초
   - 시트의 기본 요소 : 가로축, 세로축, 축제목, 막대길이, 눈금, 시트 제목, 도구설명(tool kit) 등
   - 가로-세로 시트 크기 조절
   - 마크레이블 표시
   - 시트 이름 변경 / 표시 이름 변경
   - [실습/완료] 매물 방향별 평균 거래가
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/fe949203-d2db-4aee-b047-70de4c5ef2d8/image.png)
2. 마크 패널로 차트 완성도 높이기
   - 색상, 크기, 레이블, 도구설명(미리 보기로 확인), 세부 정보
3. 와인 평균 판매가 시각화
   - [실습/완료] 국가별 와인의 평균 가격을 한눈에 확인할 수 있는 막대 차트 만들어보기
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/66a8171b-8886-48c8-8bcb-0b698bbfc103/image.png)
4. 라인 차트
   - 라인 그래프 : 시간의 흐름과 관련된 데이터에서 값의 변화를 쉽게 파악할 때 용이
   - +버튼을 누르거나 우클릭해서 연-분기-월 형식으로 바꿔줄 수 있음
   - 연속형/불연속형 으로 선택할 수 있음
     - 불연속형 : 연도를 고려하지 않고 집계
     - 연속형 : 연도까지 고려하여 집계
   - 그래프의 변화를 쉽게 파악할 수 있도록 변경할 수 있음
     - 세로축에 우클릭해서 ‘축 편집’ → ‘0포함’ 해제
   - 마크패널을 보면 라인 그래프에만 있는 ‘경로’ 버튼에서 라인 모양을 바꿀 수 있음
   - [실습/완료] 지역별 거래가격 추이
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/c62d50e3-b87b-4573-85ca-33fdb1bc8d01/image.png)
5. 와인 매입 현황 시각화
   - [실습/완료] 월별로 몇 종류의 와인을 수입했는지 확인할 수 있는 라인 차트 그리기
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/660166c6-420c-4839-88cc-801c197f7b63/image.png)
6. 파이 차트
   - 파이 그래프 : 일부와 전체의 비중/비율을 나타낼 때 용이
     - 전체에 대한 각 부분의 비율을 부채꼴로 나타냄
       - 행과 열이 바뀌어도 상관 없음
       - ‘표현방식’에서 파이차트 클릭
     - 파이 차트를 여러개 표현할 때는 크기 요소를 활용하는 경우도 있음
     - 레이블을 드래그 할 때는 이미 선택된 필드도 ctrl을 누르고 드래그 할 수 있음
     - 비율을 나타내고 싶을 때, 레이블된 필드 우클릭 해서 ‘퀵 테이블 계산’ → ‘구성 비율’ 선택
   - (참고)카운트 : 태블로에서 자동으로 생성해주는 필드
     - 조건에 해당하는 행의 개수를 세줌
   - [실습/결과] 지역별 거래 점유율
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/9a431cc3-3012-46b0-943d-908c6e1852d0/image.png)
7. 히스토그램
   - 히스토그램 그래프 : 데이터의 분포를 파악할 때 용이
     - 각 측정 값을 여러 개의 구간으로 나눔
     - ‘구간차원’ 을 변경할 때는 필드 우클릭 해서 ‘편집’ → ‘구간차원 크기’ 클릭
       - 구간 차원은 앞에 있는 값을 포함해서 나타내고 뒤에 있는 값은 포함하지 않음 i.g. 10~20 사이는 10구간으로 나타냄
     - 레이블과 도구설명은 보기 좋게 편집
     - 범례 순서 바꾸기 : 범례 우클릭 해서 ‘정렬’ → ‘정렬기준’ → ‘수동’
   - [실습/결과] 면적별 거래 분포
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/a091716c-de33-41ce-bad2-e3d8dffe293d/image.png)
8. 박스 플롯
   - 박스 플롯 그래프 : 중앙값 등 5개의 집계 값으로 데이터의 세부 분포를 나타낼 때 용이
     - 필드를 행, 세부 정보에 각각 드래그 → 우클릭 해서 ‘차원’으로 변경 → ‘표현방식’에서 활성화 된 ‘박스플롯’ 클릭
     - 회색 영역이 박스이고 좀 더 진한 회색이 데이터의 분포가 많다는 것을 의미
     - 위쪽/아래쪽 경첩, 상한/하한 수염(위스커), 구분선 등으로 데이터의 분포를 표현
   - [실습/완료] 지역별 가격 분포
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/cccae996-44e4-41f6-ae63-26afccaee15a/image.png)
9. 마개 종류별 가격 분포 시각화
   - [실습/완료] 와인 마개의 종류별로 가격 분포를 확인할 수 있는 박스 플롯을 그리기
     ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/8f9f3b82-fc0a-4105-81fa-d50c88bc133e/image.png)
10. 산점도
    - 산점도 그래프 : 두 데이터 사이의 경향성 분석에 용이
      - 거래가격-면적 필드 둘 다 측정 값이라 대응되는 값만 찍힘 → 우클릭해서 ‘차원’으로 변경
      - ‘모양’ 변경 가능
      - ‘크기’와 ‘색상’으로 지하철역 과의 거리와의 관계도 표현 가능
    - [실습/완료] 면적-가격 관계
      ![image.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/81a3ccac-627f-46a3-b35f-93293d540f36/17ce02a6-290d-46e2-9f5f-42b62488c7e1/image.png)
11. 이중 축 차트
    - 이중 축 차트 그래프 : 차트 하나에서 여러가지 정보를 확인하고 싶을 때 용이 i.g. 주식 가격과 거래량
      - 보고자하는 필드를 행에, 구분하고 싶은 필드를 열에 놓고 우클릭 후 ‘이중축’ 클릭
        - 세로축이 왼쪽/오른쪽 에 생기게 되며 이를 이중축이라고 함
      - ‘마크’ 패널이 생기며, 그 안에 세 개의 탭이 생김
        - 각 탭별로 그래프의 종류를 바꿀 수도 있음
      - 오른쪽에 있는 시트가 더 위에 표시되므로 그래프를 조정해줄 필요가 있음
        - 행 패널에서 순서를 변경해줘도 됨
        - 더 좋은 방법은 세로축을 우클릭 해서 → ‘축편집’ 클릭 → 눈금 ‘사용자 지정’
      - ‘전체’ 탭에서 색상을 ‘축’별로 지정해줄 수도 있음
      - 카운트의 ‘크기’ 탭에서 ‘수동’을 클릭하여 막대 폭을 조절해줄 수도 있음
      - ‘전체’ 탭에서 ‘레이블’ → ‘글꼴’ → ‘마크 색상 일치’로 각 그래프별 레이블 색상을 달리 해줄 수 도 있음
12. 표로 데이터 요약하기
    - 표 : 여러가지 값을 동시에 나타내고 싶을 때 사용 (그래프 대신 표가 더 직관적)
    - ‘행’ 패널, ‘열’ 패널, ‘마크’패널의 ‘텍스트’ 에 각각 원하는 데이터를 드래그
      - 태블로는 테이블에 여러 측정 값을 동시에 올릴 수도 있음
      - ‘텍스트’에 여러개의 필드를 넣으면 됨
    - 값의 비교를 위해서 해당 필드를 ‘색상’에 드래그 → 표현 방식에서 ‘하이라이트 테이블’ 선택
      - 집계를 위해 ‘분석’메뉴에서 ‘총계’ 클릭 → ‘행 총합계 표시’와 ‘열 총합계 표시’ 클릭
      - 집계는 합계 또는 평균으로 표시할 수 있음
      - 색상과 레이블의 집계 방법이 동일해야 숫자와 색상이 대응됨
      - 평균으로 표시할 때 테이블의 ‘총합계’ 부분에서 오해의 소지가 있을 수 있음
        - 우클릭 해서 ‘서식’ → ‘총합계’ 레이블 ‘전체 방향’ 으로 변경
